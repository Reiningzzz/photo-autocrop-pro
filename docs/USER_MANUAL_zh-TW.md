## 第 1 章：產品概述與核心架構

**PhotoAutoCrop Pro** 是一套專為實體老照片數位化、相簿翻拍批次裁切、拍立得與小卡典藏設計的**純本機桌面工作台**。

### 1.1 傳統掃描 vs PhotoAutoCrop Pro
- **傳統掀蓋式掃描儀**：相簿黏死無法拆卸、一次只能掃描一張、掃描一張需等待 30 秒至 1 分鐘，整理整本相簿往往需要數週時間。
- **手機隨手拍 + PhotoAutoCrop Pro**：將相簿放在桌上，用手機直接對整頁拍照（一頁包含 2~6 張老照片），一次拖入本軟體。系統在 1 秒內自動將每張照片精確分割出來、消除手機俯拍產生的梯形透視變形、擺正朝向並注入專業 300 DPI 印刷標籤！

### 1.2 100% 本機端隱私架構 (Zero-Cloud Leak)
- 所有影像運算均在您的電腦本地記憶體中完成（採用純前端 WebAssembly 與高效能本機演算法）。
- 拔掉網路線、身處飛機或無網路環境，全功能依然 100% 順暢運作。
- 無使用者行為追蹤（Zero Telemetry），不收集您的任何相片或個人中繼資料。

## 第 2 章：新手 3 步驟極速上手

```text
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│  步驟 1：啟動   │ ───>  │  步驟 2：拖入   │ ───>  │  步驟 3：匯出   │
│  雙擊執行軟體   │       │  整批相片拖進來 │       │  點擊綠色大按鈕 │

└─────────────────┘       └─────────────────┘       └─────────────────┘
```

1. **第 1 步：啟動軟體與啟用金鑰**
   - 雙擊開啟 `PhotoAutoCrop-Pro-Portable.exe` 或從開始功能表啟動。
   - 介面右上角若顯示「試用版（可試用 3 張）」，點擊「**啟用授權**」，貼上 Gumroad 購買收據中的 32 碼金鑰，按下 Enter 即可解除限制。
2. **第 2 步：拖入翻拍照**
   - 直接將拍攝好的相片檔案（或整個資料夾）拖曳進軟體中央虛線區域。
   - 系統即時啟動批次偵測，照片下方會立即出現裁切預覽縮圖與四角定位框。
3. **第 3 步：一鍵打包匯出**
   - 檢視預覽滿意後，點擊右下角綠色「**匯出全部相片 (ZIP)**」大按鈕。

## 第 3 章：相片匯入與格式相容指南 (含 iPhone HEIC 直讀)

### 3.1 支援之圖片格式
- **標準點陣圖**：JPEG (`.jpg`, `.jpeg`)、PNG (`.png`)、WebP (`.webp`)、BMP (`.bmp`)。
- **iPhone 原生翻拍格式**：HEIC / HEIF (`.heic`, `.HEIC`)。

### 3.2 iPhone HEIC 本地秒速無損轉碼
iPhone 預設翻拍照片會儲存為高壓縮率的 `.heic` 格式，在 Windows 系統中往往無法開啟。  
PhotoAutoCrop Pro 內建離線 WebAssembly 轉碼管道：
- 拖入 `.heic` 檔案時，系統自動在本機記憶體中即時解碼為超高畫質畫布點陣圖。
- **零外部依賴、零雲端轉檔**：無需先在手機另存為 JPG，也無須下載第三方轉檔工具。

### 3.3 拍攝翻拍環境的最佳實踐 (物理第一性原理)
為獲得最高辨識精度，拍攝翻拍時建議遵循以下「三要原則」：
1. **背景要對比**：白邊或淺色相紙，請放置於**深色桌面、深色桌墊或深色木紋**上拍攝。
2. **光線要漫射**：關閉手機閃光燈，避免天花板直射反光。建議站在窗邊利用白天自然漫射光，或將手機稍微傾斜 10~15 度避開燈斑（軟體會自動透視拉平！）。
3. **相紙要平整**：若相片捲翹嚴重，可用手邊透明壓克力板輕壓邊角。

## 第 4 章：AI 邊緣偵測、透視拉平與自動擺正

### 4.1 多目標智慧邊界辨識
- 軟體內建自適應邊界梯度偵測與輪廓幾何擬合，能精準區分相片邊界與相簿背景底紙。
- 支援整張翻拍照內同時存在 1 至 6 張甚至更多老相片，每張獨立分割。

### 4.2 頂級 Lanczos-4 透視校正 (Perspective Dewarp)
手機拍照時很難保持 100% 絕對垂直正上方俯拍，往往伴隨梯形透視變形。  
PhotoAutoCrop Pro 自動提取四角頂點（Top-Left, Top-Right, Bottom-Right, Bottom-Left），透過高精度幾何矩陣運算消除透視傾斜，還原出宛如高階專業平台掃描儀的平整矩形照片。

### 4.3 智能自然朝向擺正 (Orientation)
- 系統結合幾何長寬比計算與離線人像特徵偵測。
- 若翻拍之相片包含人物臉孔，系統自動辨識臉部朝向並自動旋轉擺正為正確直式視角，無需手動點擊旋轉。

### 4.4 選配：Google Gemini 視覺大模型輔助
若遇到年代久遠、相紙邊緣嚴重破碎泛黃、甚至多張相片緊密重疊的極端場景：
- 點擊右上角「**AI 設定**」，可填入個人免費的 Google Gemini API Key。
- 啟用後，系統將呼叫雲端多模態視覺模型進行超高維度語義邊界判定，專門克服極端複雜環境。

## 第 5 章：互動式 3X 放大鏡與磁性吸附微調

即便在 99% 的情況下系統自動辨識都能一鍵到位，但 PhotoAutoCrop Pro 依然為追求完美的買家提供了業界最強大的手動微調工具。

### 5.1 進入畫布標註器
點擊預覽區下方的「**微調角點**」或直接雙擊相片區域，即可進入全螢幕標註畫布。

### 5.2 局部 3X 顯微放大鏡 (Interactive Loupe)
- 當滑鼠點擊並拖曳四個角點錨點時，游標上方會即時浮現一個 **3 倍光學級局部放大鏡**。
- 放大鏡具有高對比中心準星，即使老照片邊界細微至 1 個像素，也能精準定位，大幅減輕眼睛疲勞。

### 5.3 底紙色度邊緣智慧磁吸 (Smart Snap)
- 內建色度分析演算法，能辨識老相簿經典的米黃色、米白雪花底紙、MEMO 橫線與裝訂孔。
- 拖曳角點靠近相片邊界約 25px 範圍內時，錨點會像磁鐵一樣自動吸附到真實相片邊緣。

### 5.4 實用快速鍵一覽

| 快速鍵 | 功能說明 |
| :--- | :--- |
| **`Shift` + 拖曳滑鼠** | 畫出矩形框選區域，一次選取多個相片框進行批次操作 |
| **`Delete` / `Backspace`** | 刪除目前選中的相片框 |
| **`Ctrl` + `Z`** | 復原上一步操作（支援高達 50 步歷史回退） |
| **`Ctrl` + `Y` / `Ctrl+Shift+Z`**| 重做操作 |
| **`R` 鍵** | 將選中相片順時針旋轉 90 度 |
| **`ESC` 鍵** | 關閉任何開啟中的彈窗或退出微調狀態 |
| **`[` 與 `]` 鍵** | 切換至上一張 / 下一張相片 |

## 第 6 章：300 DPI 印刷級標籤注入與批次打包匯出

### 6.1 為什麼 300 DPI 標籤如此重要？
普通截圖工具匯出的相片，解析度標頭通常預設為螢幕顯示的 72 DPI。當您將這些檔案送到沖印店或線上沖洗服務時，相館軟體會自動判定為「低解析度照片」而發出警告或拒絕沖印。

### 6.2 二進位 JFIF APP0 300 DPI 注入機制
- PhotoAutoCrop Pro 在匯出 JPEG 時，直接在二進位標頭中寫入 JFIF APP0 標籤，設定水平密度與垂直密度為 **300 DPI**。
- 同時強制將 EXIF Orientation 標籤規範化為 1（Normal），確保在所有相片檢視器中均為正向。
- 原始拍攝時間戳與相機資訊完整無損保留，符合專業家譜檔案庫數位典藏標準。

### 6.3 匯出偏好設定
在右側面板中，您可以自訂匯出設定：
- **輸出格式**：支援 JPG（預設最佳相容性）、PNG（無損透明支援）或 WebP。
- **壓縮品質**：預設為 0.95 高品質，保留最細膩的底片顆粒感。
- **自訂命名樣板**：支援 `[原檔名]_cut_[序號]`、自訂前綴或純流水序號。

## 第 7 章：相簿版型記憶 (Layout Memory) 與隨身專案檔 (.pacproj)

### 7.1 相簿版型記憶引擎 (Layout Memory)
整本家庭相簿每一頁往往具有相似的排版結構（例如每一頁都是「上橫下直兩張」或「經典四格」）。
- **先驗幾何學習**：當您在第一頁微調並確認了裁切框後，系統會自動學習相片的相對位置幾何特徵。
- **一鍵強制套用全相簿**：翻拍後續頁面時，點擊「套用相簿版型」，後續翻拍頁會立即依照先驗版型自動對齊定位！
- **反光碎框自動癒合**：翻拍具有亮面保護套的相簿時，強烈反光容易將一張照片切成 2 塊碎框。版型記憶引擎會依據先驗排版，自動辨識並將碎框「癒合」為一張完整的大相片。

### 7.2 跨電腦隨身專案檔 (.pacproj)
整理整套數千張相片的大型檔案庫時，無法在單一工作階段中完成。
- **離線 IndexedDB 即時防護**：軟體在背景即時儲存進度，就算電腦意外重開機，重新打開軟體依然保留所有工作狀態。
- **匯出 `.pacproj` 隨身專案檔**：點擊選單「檔案」➔「匯出專案進度檔」，將目前所有相片、裁切角點、核准狀態儲存為單一 `.pacproj` 檔案。
- **隨身碟跨設備同步**：將 `.pacproj` 拷貝至隨身碟，攜帶至筆記型電腦或辦公室電腦，點擊「載入專案進度檔」，1 秒還原所有微調框與照片進度，完全不需重新拉框！
