# PhotoAutoCrop Pro — Mac 測試版安裝方法與首次啟動指南（免金鑰專用版）

> **朋友測試專屬版本**：本版本已預先解除所有功能與張數限制，**完全免輸入任何金鑰**，安裝後開啟即為完整 PRO 版。  
> **隱私保證**：所有照片辨識與裁切 100% 在您自己的 Mac 本機離線運算，絕不會將任何照片上傳至網路！

---

## 第一步：確認您的 Mac 要下載哪一個安裝檔

點擊 Mac 螢幕左上角的 **蘋果圖示 ()** ➔ **「關於這台 Mac」**，查看處理器名稱：

| 您的 Mac 晶片 / 處理器類型 | 請使用哪一個 `.dmg` 安裝檔 |
| :--- | :--- |
| **Apple M1 / M2 / M3 / M4**（近年新款 Mac） | **`PhotoAutoCrop-Pro-Friends-Mac-arm64.dmg`** |
| **Intel Core**（早期舊款 Mac） | **`PhotoAutoCrop-Pro-Friends-Mac-x64.dmg`** |

---

## 第二步：正確安裝至「應用程式」資料夾

1. 雙擊打開對應的 `.dmg` 安裝檔。
2. 視窗打開後，用滑鼠將左邊的 **PhotoAutoCrop Pro** 圖示，**直接拖曳進右邊的 `Applications`（應用程式）資料夾中**。
3. **重要提醒**：請務必拖進 `Applications` 資料夾後再開啟，**不要**直接在 `.dmg` 光碟視窗裡面雙擊執行！

---

## 第三步：首次開啟放行授權（重要！僅第一次需要）

因為此為提供朋友搶先試用的測試版，尚未付費向蘋果申請官方開發者公證，首次開啟時 macOS 會出於保護機制攔截。請依照您的系統出現的提示，照以下任一方法**放行一次**即可永久正常雙擊使用：

### 情況一：提示「無法驗證開發者」或「已阻擋使用」（macOS Sonoma / Sequoia 最常見）
1. 先正常雙擊一次 `Applications` 裡的 **PhotoAutoCrop Pro**，系統會跳出無法開啟的警告視窗，先點擊 **「完成」** 或 **「好」** 關閉視窗。
2. 點擊左上角 **蘋果圖示 ()** ➔ **系統設定 (System Settings)** ➔ 左側欄位點選 **「隱私權與安全性 (Privacy & Security)」**。
3. 往下捲動到最下方的 **「安全性」** 區塊，您會看到一行提示：  
   *「已阻擋使用『PhotoAutoCrop Pro』，因為它無法驗證開發者…」*
4. 直接點擊該提示旁邊的 **「仍要打開 (Open Anyway)」** 按鈕。
5. 輸入您的 Mac 開機密碼或使用 Touch ID 指紋驗證 ➔ 再點一次 **「打開」**，軟體便會成功啟動！

### 情況二：使用快速右鍵打開（部分 macOS 版本適用）
1. 打開 Finder 進入 **應用程式 (Applications)**。
2. 按住鍵盤 **`Control`** 鍵不放再點一下 **PhotoAutoCrop Pro**（或用觸控板雙指右鍵點擊）。
3. 選擇 **「打開 (Open)」** ➔ 在跳出的確認視窗中再點擊 **「打開」**。

### 情況三：如果提示「PhotoAutoCrop Pro 已損毀，無法打開。您應該將它丟到垃圾桶」
這**不是檔案真的壞了**，而是蘋果針對「未公證之網路下載檔」加上了隔離標籤（Quarantine Flag），只要一行指令就能在 1 秒內解除：
1. 在 Mac 右上角點放大鏡 Spotlight，輸入 **「終端機」**（或 **Terminal**）並打開。
2. 完整複製以下這行指令，貼上終端機後按下 `Return`（Enter 鍵）：
   ```bash
   xattr -cr "/Applications/PhotoAutoCrop Pro.app"
   ```
3. 完成後關閉終端機，直接雙擊 **PhotoAutoCrop Pro** 即可秒開！

## 測試開始：3 步驟快速上手

1. **免金鑰確認**：打開軟體後，右上角已直接顯示綠色的 **PRO** 狀態，支援無限張數批次處理、300 DPI 印刷級匯出與 iPhone HEIC 原圖直入。
2. **匯入翻拍照片**：將整頁老相簿翻拍照（可同時包含 2～4 張照片）或整個資料夾直接拖入視窗。
3. **自動辨識與微調匯出**：
   - 點擊上方工具列 **「Batch Detect」（批次辨識）**（預設使用純本機離線演算法，無需連網）。
   - 拖曳四個角落錨點可微調邊界，也可點選右側預覽圖旋轉方向。
   - 點擊右下角 **匯出**，即可產出拉平、自動裁切好且具備 300 DPI 的高品質成品照！
   - *(補充：軟體支援中英文等多語系切換，點擊頂部右側地球圖示即可切換「繁體中文」。)*
