# PhotoAutoCrop Pro — 超簡單安裝方法（不用任何序號或密碼）

這是一個專門幫您自動整理、裁切翻拍老照片的小工具。  
**已經直接幫您開通好全部功能，完全不用輸入序號或註冊帳號！**（所有照片都在您自己電腦裡處理，不會傳到網路上。）

---

## 第一步：安裝到電腦裡（10 秒鐘）

1. 點兩下打開下載的 **`PhotoAutoCrop-Pro-Mac.dmg`** 檔案（任何蘋果電腦都可以用，不用管型號）。
2. 畫面跳出來後，用滑鼠把左邊的 **PhotoAutoCrop Pro 圖示**，直接**拉進右邊的「Applications」（藍色資料夾）** 裡面放開。
   > 小提醒：記得要拉進右邊資料夾裡喔，不要在原本的小視窗直接開！

---

## 第二步：第一次打開的小設定（只要設定這一次）

打開電腦裡的「**應用程式（Applications）**」資料夾，點兩下 **PhotoAutoCrop Pro**：

* **如果電腦跳出警告視窗說「無法驗證 / 已阻擋使用」**：別緊張！這是因為朋友自己寫的小程式沒有跟蘋果公司花錢買上架認證，只要點一下讓蘋果放行就好，步驟如下：
  1. 先按一下警告視窗上的 **「好」**（或「完成」）把它關掉。
  2. 點螢幕最左上角的 **蘋果符號 ()** ➔ 點 **「系統設定」**（舊版電腦叫「系統偏好設定」）。
  3. 在左邊清單往下找，點 **「隱私權與安全性」**。
  4. 把右邊畫面一直拉到最下面，您會看到一行字寫著 *「已阻擋使用 PhotoAutoCrop Pro...」*，點一下它旁邊的 **「仍要打開」** 按鈕！
  5. 輸入您平常開機的密碼（或按一下指紋），再點「打開」就大功告成了！

*(做完這一次以後，電腦就會記住了，下次直接點圖示就能秒開！)*

---

## 第三步：怎麼使用？

1. 打開畫面後，直接把手機翻拍的老相簿照片（整頁多張也可以）或整個資料夾**拖進視窗裡**。
2. 點上面藍色按鈕 **「批次辨識 / Batch Detect」**，電腦就會自己幫您把每一張照片框出來。
3. 確認框框沒問題（想微調拉四個角點就好），最後點右下角綠色按鈕 **「匯出」**，就能收成一張張裁切好又端正的新照片啦！
   *(如果想切換成中文介面，點畫面右上角的地球小圖示就可以切換成「繁體中文」喔！)*
