# PhotoAutoCrop Pro — macOS 初次安裝與快速放行指引

這是一個專門幫您自動整理、辨識與拉平裁切翻拍老照片的桌面工具。  
**所有照片均在您電腦本機記憶體中處理，絕不上傳至任何雲端伺服器，100% 守護個人隱私。**

---

## 第一步：安裝至電腦（10 秒鐘）

1. 點兩下打開下載的 **`PhotoAutoCrop-Pro-Mac.dmg`** 檔案（通用版 Universal，支援 Apple Silicon M1/M2/M3/M4 與 Intel Mac）。
2. 視窗跳出後，用滑鼠把左邊的 **PhotoAutoCrop Pro 圖示**，直接**拖入右邊的「Applications (應用程式)」** 資料夾中放開。
   > ⚠️ **重要提醒**：請務必拖入 Applications 資料夾後再啟動，請勿直接在 DMG 磁碟映像檔中執行！

---

## 第二步：首次啟動安全性放行（只需設定一次）

macOS Gatekeeper 預設會對非 Mac App Store 下載之獨立軟體顯示安全性提示。請依照以下推薦方式快速放行：

### 招式 1：按住 Control 鍵點選「打開」（最推薦・最快速）

1. 打開 Finder，進入「**應用程式 (Applications)**」資料夾。
2. **按住鍵盤上的 `Control` 鍵不放**，同時用滑鼠點選 **PhotoAutoCrop Pro** 圖示（或按滑鼠右鍵）。
3. 在彈出的選單中，點選「**打開 (Open)**」。
4. 系統會跳出確認對話框，此時視窗中會出現「**打開**」按鈕，點擊「打開」即可順暢啟動！  
   *(提示：此操作只需在第一次開啟時執行一次，macOS 將永久記錄信任，往後直接連按兩下即可啟動。)*

---

### 招式 2：系統設定放行法（適用 macOS Sequoia / Sonoma）

1. 若雙擊被阻擋，先點擊警告視窗上的「好」關閉提示。
2. 點擊螢幕左上角「蘋果選單 ()」➔「**系統設定**」➔ 左側「**隱私權與安全性**」。
3. 捲動至最下方「安全性」區塊，會看到提示：「已阻擋使用 PhotoAutoCrop Pro...」，點擊旁邊的「**仍要打開**」按鈕。
4. 輸入您的開機密碼（或按壓 Touch ID 指紋），再點「打開」即可。

---

### 招式 3：終端機一鍵解除隔離指令（排除「已損壞」或嚴格攔截）

若系統出現「應用程式已損壞，您應該將它丟到垃圾桶」或無法透過介面放行，這是 macOS 對網路下載檔案自動附加之 quarantine 隔離標籤。打開「終端機 (Terminal)」貼入以下指令並按 Enter 即可瞬間解除：

```bash
xattr -cr "/Applications/PhotoAutoCrop Pro.app"
```

> **技術說明**：指令中的 `xattr -cr` 會遞迴清除應用程式套件上的隔離屬性，路徑包含雙引號以防空格跳脫錯誤。執行完畢後直接雙擊 App 即可正常打開。

---

## 第三步：快速上手 3 步驟

1. **拖入相片**：直接把手機翻拍的老相簿照片（整頁多張亦可）或整個資料夾拖入視窗中。
2. **批次辨識**：點擊上方「**批次辨識**」，系統自動將每張照片分割並校正透視傾斜。
3. **打包匯出**：檢查裁切框無誤後，點擊右下角「**匯出相片**」，即可打包下載注入 300 DPI 印刷標籤之高清相片檔案！
   *(若需切換語言，點擊右上角地球圖示即可切換繁體中文、English 等多國語系。)*
