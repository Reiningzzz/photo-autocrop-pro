macOS Gatekeeper protects your Mac by default against unnotarized independent software. You can authorize PhotoAutoCrop Pro in seconds using either method below:

✨ Recommended Method (Fastest)

Method 1: Control + Click Open

Bypasses Gatekeeper without modifying any system security settings:

  1. In Finder, open your Applications folder.
  2. Hold down the Control key and click the PhotoAutoCrop Pro icon (or right-click).
  3. In the context menu, select Open.
  4. A confirmation prompt appears with an "Open" button. Click Open to launch.

* Note: This is only required on the very first launch. macOS remembers your approval permanently.

Method 2: Clear Quarantine Flag via Terminal

If macOS displays "App is damaged and can't be opened" or strictly prevents launch, remove Apple's automated download quarantine attribute with one command:

Terminal
