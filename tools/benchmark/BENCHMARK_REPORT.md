## 🔬 二、 評測指標科學定義 (Methodology)

1. **平均交併比 (Mean IoU, Intersection over Union)**：
   $$\text{IoU} = \frac{\text{AI 偵測框} \cap \text{真實實體相紙 (Ground Truth)}}{\text{AI 偵測框} \cup \text{真實實體相紙 (Ground Truth)}}$$
   * **數值含義**：衡量 AI 邊界是否咬齊實體相紙物理切線。數值越高，代表既沒有腰斬漏掉相片內容，也沒有吃進相簿底紙背景。

2. **目標分離成功率 (Separation Accuracy)**：
   * 檢驗模型是否具備識別「一頁相簿上下貼了多張獨立沖印相片」的能力（如 4×6 吋插袋相簿）。
   * 只有當頁面中的每張獨立相片皆被成功分割為個別裁切框時才計為命中。

3. **端到端延遲 (End-to-End Latency)**：
   * 包含圖片前處理傳輸、雲端神經網路推理與 JSON 結構化解析回傳的完整端到端耗時（毫秒）。

## 💡 四、 結論與消費者選型指南（立足真實客觀數據）

1. **追求極限省時（大量批次作業首選）**：推薦選擇 **Gemini Flash-Lite**
   * **實測優勢**：端對端平均單張僅需 **2.4 秒**（耗時約標準版的 1/7），多照片分離正確率達 **100.0%**！
   * **客觀局限**：在磨石子等複雜強紋理地面，輕量模型對相紙邊界的識別重疊度約 38.4%（而在一般插袋相簿與肖像照則高達 85.7%～89.8%）。
   * **最佳情境**：適合一口氣處理數百張老照片快速抓出各張位置，若遇複雜背景可搭配手動拖拉微調。

2. **追求精準咬齊邊界（高精準度主流首選，推薦 95% 用戶）**：強烈推薦預設的 **Gemini Flash**
   * **實測優勢**：綜合平均邊界重疊度高達 **90.2%**！尤其在面對極具挑戰的「磨石子地板」樣本時，邊界交併比突破至 **97.6%**，完美保護相片人物腳部與背景完整性，絕不腰斬。
   * **客觀耗時**：因進行多模態全解析度深度推理，端對端往返耗時約需 **7 ~ 17 秒**。
   * **最佳情境**：老相簿數位化、色彩與背景繁複、追求一步到位裁切精準度的首選。

3. **關於旗艦型 (Gemini Pro) 之使用現況說明**：
   * Google 官方目前在免費 API 方案中限制了 Pro 模型的公共調用權限（未綁定信用卡之金鑰會回傳 404/429）。軟體內部已預先配置企業端點，建議已綁定 Google Cloud 結算帳戶之專業用戶使用。
